How the number is made. Each protocol's implied value is its TVL times a comps multiple — the median market-cap / TVL of the live-token protocols in its own category, blended 0.65 / 0.35 with the market-wide median — times a growth factor from its seven-day TVL change and a maturity factor from how long it has run with no token. A category with fewer than three live peers falls back to the market-wide median. The page recomputes every row from those same figures, so what you see is what the board file carries.

An implied value is an estimate, not a price. A protocol records no token; that is not proof it has none, and nothing here predicts whether or when a token is issued.
